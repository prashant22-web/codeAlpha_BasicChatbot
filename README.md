# Basic Python Chatbot 🤖

## About

This is a simple rule-based chatbot created using Python. It interacts with the user by taking input and giving predefined responses based on the user's message.

## Features

* Takes user input
* Responds to basic questions and messages
* Uses `if`, `elif`, and `else` conditions
* Uses functions
* Allows the user to continue the conversation
* Provides an exit option

## Concepts Used

* Python Functions
* Input and Output
* If / Elif / Else
* While Loop
* String Handling
* Basic Python Logic

## How It Works

1. The user enters a message.
2. The chatbot checks the input.
3. It matches the message with predefined conditions.
4. The chatbot gives an appropriate response.
5. The conversation continues until the user chooses to exit.

## Example

```text
You: hello
Bot: Hello! How are you?

You: what is your name?
Bot: I am a basic Python chatbot.

You: bye
Bot: Goodbye! Have a nice day.
```

## Purpose

This project was created to practice Python fundamentals and understand how conditions, functions, loops, and user input can be combined to build a simple interactive program.
